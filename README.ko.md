자연수를 나선 모양으로 배치하고 소수의 분포와 소수생성 이차식의 성질을 살펴보는 **단일 HTML 프로그램**입니다. 탐색 범위는 **1부터 100조(10¹⁴)**까지입니다.

**현재 정식 버전: v1.4.0 (2026-10-30)** · [MIT 라이선스](LICENSE)

## 주요 기능

- **다섯 가지 모드**: 사각 울람·육각·삼각·Sacks 나선·클라우버 삼각형.
- **최대 100조 탐색**: WASM 소수 체, Web Worker, 정확한 소수 판정 및 캐시를 활용한 화면 이동과 확대.
- **선택점 기준 수열**: 점을 선택해 이차식 후보를 탐색하고 유한 구간의 소수 개수·비율을 계산.
- **상수항 c 탐색**: 사각·육각·삼각·Sacks에서 **±7,000만**, 클라우버 전용 기능은 기존 **최대 ±100억** 유지.
- **미니맵 7단계**: 1억·10억·100억·1000억·1조·10조·100조. 다섯 모드 모두 추정 밀도에 따른 밝기를 적용하고, 수학적으로 소수가 불가능한 가지는 숨깁니다. **추정 밀도 20% 이상이면 최고 밝기**로 표시합니다.
- 영어·한국어 UI와 마우스·키보드 조작, 수열 저장.

## v1.4.0 변경 사항

- 탐색 상한을 **1조에서 100조**로 확장.
- 멀리 떨어진 사각 나선의 좌우 변·대각 모서리 소수 계산 가속 및 중복 화면 갱신 감소.
- 선택점 통계 Worker 예열, 홀짝·대칭 수열 최적화, 법 2 소수 개수 계산 오류 수정.
- 모든 나선 모드의 미니맵 밀도 시각화 통합.
- 일반 나선의 상수항 탐색을 ±7,000만으로 확장.

자세한 사항은 [한국어 릴리스 노트](RELEASE_NOTES_v1.4.0.ko.md), [변경 기록](CHANGELOG.md), [검증 기록](RELEASE_QA_v1.4.0.md)을 참고하세요.

## 해석과 한계

표시된 소수율은 **유한 구간에서의 통계**이며 무한히 많은 소수를 생성한다는 증명이 아닙니다. 넓은 미니맵에서의 밝기는 작은 소수 검사 결과로 보정한 **추정치**이며 모든 항을 확인한 실제 비율과 구분됩니다. 일부 조건에서만 정밀 항 전수 검사를 사용합니다. 사용 환경에 따라 성능은 달라집니다.

저장한 수열은 현재 브라우저에만 저장됩니다. 검증 명령: `python3 scripts/verify_release.py --require-node`.
