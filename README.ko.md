**1부터 1조(10¹²)까지** 울람 나선을 탐색하고, 소수를 많이 만들어 내는 이차식을 찾아보는 단일 HTML 웹 애플리케이션이다.

## 실행

- **웹 공개:** GitHub Pages를 활성화하면 `index.html`을 통해 브라우저에서 바로 실행할 수 있다.
- **독립 실행:** [`Ulam Spiral & Prime-Generating Quadratic Explorer.html`](Ulam%20Spiral%20%26%20Prime-Generating%20Quadratic%20Explorer.html)을 내려받아 브라우저에서 열면 된다.
- 설치나 별도의 백엔드 서버가 필요하지 않다.

## 주요 기능

- **최대 1조 탐색:** 현재 화면 및 주변의 소수 정보만 계산하고 재방문 시 캐시를 재활용한다. 1조 이하의 모든 소수를 일괄 생성하는 프로그램은 아니다.
- **울람 나선 시각화:** 숫자 이동, 화면 이동 및 확대/축소, 점 선택과 소수 표시.
- **소수생성 이차식 분석:** 선택한 점을 통과하는 격자선을 이차식으로 나타내고 소수 비율을 분석한다. 기본 방향뿐 아니라 여러 정수·유리 기울기를 지원한다.
- **이차식 탐색:** 계수 `a`, `b`, `c` 후보를 탐색하고 작은 소수로 선별한 뒤 상위 후보의 소수 비율을 검증한다. **한 번에 탐색할 수 있는 c 값의 범위는 최대 700만 개**이다.
- **수열 저장:** 마음에 드는 수열을 브라우저 로컬 저장소에 보관하고 다시 불러온다.
- **미니맵과 한영 전환:** 모바일 화면을 고려한 UI, 범위를 조절할 수 있는 미니맵, 영어·한국어 전환.

## 1조까지 계산

1조까지 소수인지 모두 계산해 메모리에 넣는 방법은 사용하지 않는다. **현재 보이는 부분에 필요한 소수만 계산**하며, 울람 나선의 가지에서는 숫자가 짧은 연속 구간으로 대응한다는 기하학적 특징을 이용한다.

원거리 모서리에서는 서로 다른 두 가지 영역을 공통 Worker 예산으로 처리하고, 캐시에 계산 결과를 저장한다. WebAssembly와 Web Worker를 사용하며 지원되는 경로에는 JavaScript 대체 처리도 들어 있다. 계산 도중 불필요한 전체 화면 그리기를 줄이기 위해 모서리 중간 갱신은 약 **160ms 간격**으로 제한하며, 최종 결과는 즉시 갱신 요청한다.

## 사용 방법

1. HTML 파일 또는 GitHub Pages 주소로 실행한다.
2. **이동** 입력칸에 1조 이하의 자연수를 입력하거나 화면을 이동한다.
3. 점을 클릭하여 그 점을 지나는 이차식을 분석한다.
4. **탐색**으로 새로운 수열을 찾고 **저장**으로 보관한다.

최초 방문 시에는 해당 구역의 계산 시간이 발생하며, 재방문 캐시는 메모리 상황에 따라 유지·정리될 수 있다. 미니맵의 연속적인 소수 밀도 배경은 실제 소수의 전수 결과가 아닌 **근사 시각화**이다.

## 발전 과정

**1억 → 4억 → 9억 → … → 49억 → 100억 → 1조.** 초기에는 한꺼번에 계산 가능한 소수 체 범위를 늘리는 것이 목표였지만, 현재는 필요한 공간만 선택해 처리하도록 알고리즘과 캐시 구조를 발전시켰다.

## 사용 환경과 제한

최근 Chromium 계열, Firefox 등 WebAssembly·Web Worker를 지원하는 브라우저를 권장한다. 속도는 CPU, 메모리, 브라우저, 화면 크기에 따라 달라진다. 저장된 수열은 각 브라우저의 로컬 저장소에 있으며 기기 간 자동 동기화되지 않는다.
