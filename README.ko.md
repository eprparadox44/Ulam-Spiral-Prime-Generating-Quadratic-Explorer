자연수를 나선 모양으로 배치하고 소수를 표시하면, 점들이 예상 밖의 직선을 이루기도 합니다. 이 탐색기는 그런 패턴을 살펴보고, 관련된 이차식을 찾아 소수생성 비율을 비교할 수 있도록 만든 웹 애플리케이션(이라 쓰고 장난감이라 읽습니다.)입니다.

**1부터 1조(10¹²)까지** 탐색할 수 있으며, 별도 설치 없이 HTML 파일 하나로 실행됩니다.

## v1.3.0 주요 변경 사항

지난 GitHub 공개 버전인 **v1.2.26** 이후의 핵심 업데이트는 두 가지입니다.

### 1. 클라우버 삼각 나선 추가

기존 **사각·육각·삼각·Sacks 나선**에 **클라우버 삼각(Klauber Triangle)** 모드를 추가했습니다. 같은 자연수라도 배치 방식에 따라 서로 다른 소수 분포와 선형 패턴을 관찰할 수 있습니다.

클라우버 모드에서는 선택한 점을 지나는 수열을 살펴보고, `G(n)=an²+bn+c` 형태의 이차식을 탐색할 수 있습니다. 표시되는 수열은 **자연수 `n≥1`**을 입력하는 기준으로 통일했습니다.

클라우버 전용 직선 필터와 상수항 **±100억** 탐색도 지원합니다. 탐색 결과는 유망한 후보를 선별한 것으로, 전체 범위의 최적해를 보장하지는 않습니다.

### 2. 희소 수열의 미니맵 가시성 개선

소수가 드물게 생성되는 수열은 미니맵에서 분포를 알아보기 어려웠습니다. 이를 개선하기 위해 **1억·10억 미니맵**에 조건부 정밀 밀도 표시를 추가했습니다.

최소 확대 상태의 본 화면에서 소수가 **약 10개 이하로 나타날 것으로 예상되는 수열**에 한해 정밀 표시를 적용합니다. 이 조건은 소수 출현 확률과 화면상의 기하학적 경로를 이용한 **추정**이며, 실제 소수 개수가 10개 이하라는 뜻은 아닙니다.

조건을 만족하고 계산량 한도 내에 있으면, **해당 미니맵 범위에 속하는 수열의 유효한 항을 모두 소수 판정**합니다. 밝기는 수열의 국소적인 소수 비율을 나타냅니다. 계산량이 지나치게 큰 경우와 다른 확대 단계에서는 기존의 선 표시를 사용합니다.

미니맵 범위는 **1억 → 10억 → 100억 → 1000억 → 1조**의 다섯 단계이며, `+`는 확대, `−`는 축소입니다.

## 주요 기능

* **다양한 나선 비교:** 사각·육각·삼각·Sacks·클라우버 삼각 나선에서 동일한 자연수의 소수 분포를 비교합니다.
* **숫자와 패턴 탐색:** 1조 이하의 자연수로 이동하고, 점을 선택해 소수 여부 및 관련 수열을 확인합니다.
* **이차식 분석과 탐색:** `P(n)=an²+bn+c`의 계수를 바꾸거나 후보를 탐색하며 유한 구간의 소수생성 비율을 비교합니다.
* **수열 강조와 저장:** 관심 있는 수열을 나선에 표시하고 브라우저에 저장해 다시 살펴볼 수 있습니다.

화면 이동·확대·축소, 한국어/영어 전환, PC 및 모바일 화면을 지원합니다. 저장한 수열은 **현재 브라우저에만 보관**되며 다른 기기로 자동 동기화되지 않습니다.

## 결과를 해석할 때

표시되는 소수생성 비율은 **조사한 유한한 구간의 통계**입니다.

큰 자연수 `N` 부근에서 일반적인 소수 밀도를 가늠할 때는 소수정리의 `1/ln(N)`을 참고할 수 있습니다. 다만 개별 이차수열의 소수생성 비율은 해당 식의 나눗셈 구조에 따라 달라집니다.

미니맵에서 **정밀 밀도 표시의 적용 여부는 추정**으로 결정하지만, 적용된 경우의 소수 판정은 계산 한도 내에서 **해당 수열 항에 대한 전수검사**입니다.

계산 속도는 브라우저, 기기 성능, 탐색 범위에 따라 차이가 있을 수 있습니다.
