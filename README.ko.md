자연수를 나선 모양으로 배치하고 소수의 분포와 소수생성 이차식의 성질을 살펴보는 **단일 HTML 프로그램**입니다. 탐색 범위는 **1부터 1000조(1P, 10¹⁵)**까지입니다.

**현재 정식 버전: v1.5.0 (2026-11-04)** · [MIT 라이선스](LICENSE)

## 실행

- [**웹에서 실행 (GitHub Pages)**](https://eprparadox44.github.io/Ulam-Spiral-Prime-Generating-Quadratic-Explorer/)
- [**독립 실행 HTML 다운로드**](Ulam%20Spiral%20%26%20Prime-Generating%20Quadratic%20Explorer.html)

HTML을 내려받아 최신 브라우저에서 열면 됩니다. 별도의 설치나 빌드가 필요하지 않습니다.

## 주요 기능

- **다섯 가지 모드**: 사각 울람·육각·삼각·Sacks 나선·클라우버 삼각형.
- **최대 1000조(1P) 탐색**: WASM 소수 체, Web Worker, 정확한 소수 판정 및 캐시를 활용한 화면 이동과 확대.
- **선택점 기준 수열**: 점을 선택해 이차식 후보를 탐색하고 유한 구간의 소수 개수·비율을 계산.
- **상수항 c 탐색**: 사각·육각·삼각·Sacks에서 **±2억 2,000만**, 클라우버는 별도 **±2억 8,000만** 탐색 범위를 사용하며 기하학 필터를 선택할 수 있음.
- **미니맵 8단계**: 1억·10억·100억·1000억·1조·10조·100조·1000조. 다섯 모드 모두 추정 밀도에 따른 밝기를 적용하고, 수학적으로 소수가 불가능한 가지는 숨깁니다. **추정 밀도 20% 이상이면 최고 밝기**로 표시합니다.
- 영어·한국어 UI와 마우스·키보드 조작, 수열 저장.

## v1.5.0 주요 업데이트 — 1P 확장

## 이전 v1.4.7 변경 사항

- **‘이 식으로 바로 이동’ 복구**: 상수항 c 탐색에서 저장한 수식에는 원래 선택 지점 정보가 없으므로 버튼을 눌러도 화면이 움직이지 않던 문제 수정. 현재 카메라와 가까운 유효한 수식 생성값을 찾아 바로 이동하도록 개선.
- 원본 선택점이 남아 있는 저장 수식은 이전과 동일하게 그 점으로 이동. 이전 범위를 벗어난 저장식의 위치는 탐색 범위 안의 생성값으로 대체.
- 다섯 나선 모드의 실제 Chromium 버튼 동작 및 기존 저장식 동작 검증. 동기 소수 전수 검색 없이 즉시 이동.

### 이전 v1.4.6 변경 사항

- 100조 육각 모드에서 기존 8만 소수 용량 제한으로 JavaScript 폴백이 실행되던 경로를, 작은 소수 54개와 결정적 Miller–Rabin 판정을 이용하는 새로운 WASM 소수 엔진으로 교체. WASM을 사용할 수 없거나 비트맵 자체 검증에서 실패하면 기존 정확한 JavaScript 경로 유지.
- 같은 브라우저에서 실측한 내부 화면의 소수 계산은 약 2.6~5배 빨라졌고, 매우 좁은 외곽 화면에서는 약 1.05~1.11배였다. 두 화면의 소수 비트맵은 기존판과 일치. 기기·화면·부하에 따라 결과는 달라질 수 있음.

### 이전 v1.4.5 변경 사항

- 100조 외곽의 육각 나선에서 확대 미니맵이 사각 나선 좌표 범위에 걸려 현재 위치 및 강조 수열이 보이지 않던 문제 수정.

### 이전 v1.4.4 변경 사항

- 클라우버 c 탐색을 **±100억 → ±9천만**으로 조정.
- 클라우버의 기하학적 직선 필터를 **|기울기| ≥ 1/2 → ≥ 1/8**로 확대. 최소 연속 5만 행 조건은 유지.
- 기울기 1/8 계열 탐색을 위해 a=1, b=−7과 b=9 추천 조합 추가.
- 추가된 기울기의 c 구간 계산을 정확한 구간 합집합 알고리즘으로 보정.
- 화면 예시 G(n)=n²−7n+89,999,969는 실제 격자에서 연속 2행에 해당하므로 5만 행 필터로는 제외됨. 이 수식도 찾으려면 필터 해제 가능.

### 이전 v1.4.3 변경 사항

- 사각·삼각·삭스·클라우버의 초기 그리기·화면 계산 및 기하학 후보 생성 경로 최적화.
- 삼각·클라우버 선택점에서 격자 기하학적으로 검증한 추천 후보를 추가하고 클라우버 직선 후보 계산을 가속.

- 100조 탐색 상한, 다섯 모드, 정확 통계 계산 경로, 수열 저장, 한국어·영어 UI 유지.

## 해석과 한계

표시된 소수율은 **유한 구간에서의 통계**이며 무한히 많은 소수를 생성한다는 증명이 아닙니다. 넓은 미니맵에서의 밝기는 작은 소수 검사 결과로 보정한 **추정치**이며 모든 항을 확인한 실제 비율과 구분됩니다. 일부 조건에서만 정밀 항 전수 검사를 사용합니다. 사용 환경에 따라 성능은 달라집니다.

저장한 수열은 현재 브라우저에만 저장됩니다. 검증 명령: `python3 scripts/verify_release.py --require-node`.
